# 작품 페이지 문법 레퍼런스

[← 문서 목록으로](./README.md)

작품 · 캐릭터 · 설정 문서 본문은 [marked.js](https://marked.js.org/) 기반 표준 마크다운 위에, 갈피 전용 확장 문법(위키 서식 + 시각화 매크로)을 더해서 렌더링됩니다. 예시에 쓰인 이름 · 세계관은 전부 가상의 샘플입니다.

> 대부분의 매크로는 에디터에 붙어있는 **매크로 툴바**(표 · 차트 · 게이지 · 타임라인 버튼)로 자동 삽입되므로, 아래 문법을 직접 외워서 손으로 칠 일은 많지 않습니다. 이 문서는 "그 버튼이 실제로 뭘 만드는지"와 "손으로 빠르게 칠 때"를 위한 레퍼런스입니다.

## 기본 서식

| 문법 | 결과 |
|---|---|
| `**굵게**` | **굵게** |
| `_기울임_` | *기울임* |
| `--취소선--` | ~~취소선~~ |
| `[빨강 텍스트를 색으로]` → `[red:빨강 텍스트를 색으로]` | 색 있는 텍스트 |

색 지정은 `red` / `blue` / `black` / `white` 같은 키워드 외에, `bg-yellow`처럼 `bg-` 접두사로 배경색을, 혹은 `[#ff8800:내용]`처럼 임의의 CSS 색상값도 그대로 쓸 수 있습니다.

```
[폰트:돋움:이 구절만 다른 서체로]
[크기:24:이 구절만 24px로]
[정렬:중앙:이 문단은 가운데 정렬]
[들여쓰기:
첫 줄도, 다음 줄도
전부 들여써서 보여줍니다.
]
```

`폰트`는 `궁서` `바탕` `돋움` `굴림` `명조` 같은 기본값 외에, 문서에 등록해둔 커스텀 폰트 이름도 그대로 받습니다. `정렬`은 `좌측` `중앙` `우측` 세 값만 허용됩니다.

## 인용 / 각주 / 백링크

줄 맨 앞에 `|`를 붙이면 인용문 블록이 됩니다.

```
|이 문단은 통째로 인용문 스타일로 보입니다.
|여러 줄을 이어 쓰면 한 블록으로 묶입니다.
```

각주는 본문 어디서나 `[* 내용]`으로 삽입하며, 번호가 자동으로 매겨지고 마우스를 올리면 내용이 팝오버로 뜹니다.

```
용의 숨결은 차갑다[* 흔히 알려진 것과 달리, 이 세계관의 용은 냉기 속성을 가진다].
```

같은 작품의 캐릭터 이름이나 다른 작품의 제목과 문자열이 일치하면, `[[문서명]]`으로 감싼 텍스트가 클릭 가능한 링크가 됩니다.

```
그날 [[리안]]은 [[아르카디아 연대기]] 속 예언을 처음 들었다.
```

## 표

`||`로 감싼 셀을 이어 쓰면 표 한 행이 됩니다. 첫 행은 자동으로 헤더로 처리됩니다.

```
||이름||소속||직위||
||리안||은빛 기사단||단장||
||세이||은빛 기사단||부단장||
```

셀 맨 앞에 `<태그>`를 붙이면 정렬 · 병합 · 헤더 여부를 셀 단위로 제어할 수 있고, 콤마로 여러 개를 함께 쓸 수 있습니다.

| 태그 | 의미 |
|---|---|
| `<left>` `<center>` `<right>` | 셀 정렬 |
| `<-2>` | 오른쪽으로 2칸 병합(colspan) |
| `<\|2>` | 아래로 2칸 병합(rowspan) |
| `<h>` | 0번 행이 아니어도 해당 열을 헤더(th)로 표시 |
| `<nr>` | 0번 행이어도 헤더 처리하지 않음(행 헤더 끄기) |

```
||<center,-2>파티 정보||
||<h>이름||소속||
||리안||은빛 기사단||
```

**주의**: 표 셀 안에서 굵게는 `**`가 아니라 `~내용~`으로 씁니다. 표 편집기가 굵게를 이 기호로 저장하기 때문에, 셀 밖 본문과 문법이 다릅니다.

## 스포일러

```
[스포일러]범인은 사실 부단장이었다.[/스포일러]
```

클릭하기 전까지 텍스트가 검게 가려집니다.

## 대화 / 대사 로그

캐릭터 아바타와 말풍선이 있는 대화 UI를 만듭니다. `우대화`는 오른쪽 정렬(주로 시점 인물), `대화`는 왼쪽 정렬입니다. 표정은 선택 사항입니다.

```
[대화: 리안(당황):] 그게 무슨 소리야? [/대화]
[우대화: 세이:] 이제 와서 놀라긴. [/우대화]
```

아바타 이미지는 `{작품명}_{이름}_{표정}.png` (표정이 없으면 `{작품명}_{이름}.png`) 규칙으로 캐릭터 이미지 폴더에서 자동으로 찾습니다.

## 위젯 매크로

수치를 넣으면 SVG 그래프로 시각화되는 매크로들입니다. 값은 숫자를 직접 써도 되고, `EX·SSS·SS·S+·S·S-·A+·A·A-·B+·B·B-·C+·C·C-·D+·D·D-·E·F` 같은 랭크 문자열을 쓰면 자동으로 점수(0~100)로 환산됩니다.

### 스탯 (레이더 차트) — 항목 3개 이상 필요

```
[스탯: 검술=S, 마력=A+, 체력=B, 인내=SS]
```

### 성향 (2D 매트릭스) — X축, Y축 값 2개

```
[성향: 이성적=80, 신중함=35]
```

### 게이지 (막대 그래프) — `현재/최대` 형식, `/최대` 생략 시 100 기준

```
[게이지: 체력=72/100, 마나=40/60, 사기=90]
```

### 타임라인 — 한 줄에 하나씩, `::::`로 날짜/제목/설명 구분

```
[TIMELINE]
1년차 봄::::수도 도착::::은빛 기사단에 정식 입단
2년차 여름::::첫 원정::::북부 국경에서 첫 전투를 치름
[/TIMELINE]
```

### 관계도

`RELATION_GRAPH`는 노드/화살표 좌표가 들어간 JSON을 받는 매크로로, 보통 손으로 치지 않고 관계도 편집기 UI로 만듭니다. 화살표 종류는 `->`(단방향), `<->`(양방향), `--`(점선/약한 관계)를 지원합니다.

```
[RELATION_GRAPH]
{"nodes":[{"id":"1","label":"리안","x":150,"y":100},{"id":"2","label":"세이","x":400,"y":100}],
 "edges":[{"source":"1","target":"2","type":"<->","desc":"신뢰","descRev":"존경"}]}
[/RELATION_GRAPH]
```

### 로그탭

색상별 탭으로 구분된 기록 박스입니다. 탭 이름은 `내용` `파랑` `초록` `노랑` `빨강` `사전` `설정` `기록` 중 하나입니다.

```
[로그탭:설정] 이 세계관의 마력은 감정과 직결되어, 격한 감정 상태에서 위력이 증폭된다. [/로그탭]
```

## 숨은 메타데이터

문서 본문 맨 앞뒤에는 `[META_DATA:{...}]` 형태로 표지 이미지 배율, 테마 지정 같은 화면 설정값이 JSON으로 숨어 있을 수 있습니다. 각 편집 화면(표지 조정, 테마 선택 등)이 자동으로 읽고 쓰는 영역이라 직접 손으로 편집할 일은 없습니다.
