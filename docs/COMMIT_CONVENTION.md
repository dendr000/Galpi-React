# Git 커밋 메시지 컨벤션 (Commit Convention)

## 1. 커밋 메시지 기본 구조
타입(Type): 제목(Subject)

본문(Body) (선택 사항)

꼬리말(Footer) (선택 사항)

---

## 2. 타입 (Type) 정의
| 타입 명칭 | 설명 및 사용 시기 |
| :--- | :--- |
| **feat** | 새로운 기능 추가 |
| **fix** | 버그, 오류 수정 |
| **docs** | 문서 수정 (README.md, 주석, 폴더 트리 등) |
| **style** | 코드 포맷팅, 세미콜론 누락 등 코드 변경이 없는 경우 (CSS UI 변경은 design 사용) |
| **design** | CSS 등 사용자 UI/UX 디자인 변경 |
| **refactor** | 코드 리팩토링 (기능 변화 없이 구조만 개선) |
| **test** | 테스트 코드 추가 및 수정 |
| **chore** | 빌드 업무, 패키지 매니저 수정, 패키지 설치 (`package.json` 변경 등) |
| **rename** | 파일 혹은 폴더명을 수정하거나 옮기는 작업만인 경우 |
| **remove** | 파일을 삭제하는 작업만 수행한 경우 |

---

## 3. 작성 규칙 (Rules)
* **제목(Subject):** 50자 이내로 작성하며, 명사형 어미로 끝냅니다. (예: `feat: 로그인 기능 추가`)
* **본문(Body):** 선택 사항이며, '무엇을', '왜' 변경했는지 상세히 작성합니다. 72자마다 줄바꿈을 합니다.
* **영문/국문 혼용:** 타입은 영문 소문자로 작성하고, 제목과 본문은 직관적인 한글로 작성하는 것을 원칙으로 합니다.

## 4. 커밋 메시지 예시
### 기능 추가 예시
feat: 캐릭터 썸네일 일괄 조정 모달 추가

- 드래그 앤 드롭을 통한 Y축 위치 조정 기능 구현
- 썸네일 배율(Scale) 조작 슬라이더 추가

### 버그 수정 예시
fix: 썸네일 일괄 변경 후 갤러리 미반영 오류 수정

- 모달에서 저장 시 dynamicProperties JSON 문자열 강제 갱신 로직 추가
- WorkDetailPage.jsx 렌더링 시 cardImgScale 스타일 바인딩 누락 해결

### 문서 및 설정 변경 예시
docs: 프로젝트 폴더 트리 구조 문서화 적용
chore: @use-gesture/react 패키지 설치
